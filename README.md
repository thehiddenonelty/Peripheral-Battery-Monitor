PeripheralBatteryMonitor
无线外设电量监控工具

A lightweight Windows application for monitoring battery levels of wireless peripherals, including mice, keyboards, and headsets.
一款轻量级 Windows 无线外设电量监控软件，支持查看鼠标、键盘和耳机等外设的电池电量。
